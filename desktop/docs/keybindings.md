# Bootsy desktop keys

## Niri

- `Super+T`: terminal
- `Super+D`: DMS Spotlight
- `Super+Shift+E`: exit confirmation
- `Super+Shift+?`: Niri shortcut overlay

Niri otherwise uses Fedora's packaged default configuration. Personal changes
belong in `~/.config/niri/local.kdl`.

## Sway

- `Super+Return`: terminal
- `Super+D`: DMS Spotlight
- `Super+Shift+E`: exit confirmation
- `Super+Shift+C`: reload configuration

DMS supplies the panel and session controls; Waybar remains an optional
fallback.
